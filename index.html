How I work

I start with the person using the product, then let data and testing guide each decision.

ResearchTalk to users and find the real task.
FlowsMap the shortest path to the goal.
WireframesSketch layouts before styling.
PrototypeBuild clickable versions in Figma.
TestWatch people use it, then refine.

AgriConnect

An AI-powered app that gives farmers market prices, crop disease detection from a photo, and financial help in one place.

Role: UX and UI design

  • Mapped user flows and screens for three core tasks so farmers reach each one in a few taps.
  • Kept the interface simple and easy to scan for people who need quick answers.
  • Showed machine learning results clearly so farmers can decide with data.

Emergency Assistance System

An Android app for emergencies that keeps working with poor connectivity, using Bluetooth mesh for offline communication, plus a dashboard for responders.

Role: UX and UI design

  • Designed a short, simple help flow for people in an emergency.
  • Built a Government Dashboard so responders can see incoming requests.
  • Designed for low-connectivity situations with offline mesh messaging.
